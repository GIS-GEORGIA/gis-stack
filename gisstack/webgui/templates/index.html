7ა. არსებული პროგრამები (დაყენებამდე)

სანამ ჩვენს სტეკს დავაყენებთ, სერვერზე ვამოწმებთ, უკვე ხომ არ დგას PostgreSQL, Tomcat, GeoServer, QGIS Server, MapProxy, Caddy ან სხვა web სერვერი. თითოეულზე შეგიძლია აირჩიო: დაშენება (PostgreSQL: ვიყენებთ არსებულს), წაშლა (ჯერ ბექაფი), გამოყენება ჩვენში (ბექაფი, წაშლა, დაყენება, შემდეგ ბაზების / GeoServer-ის workspace-ების / QGIS პროექტების / Caddy-ს საიტების გადმოტანა) ან დატოვება. გეგმას Deploy ავტომატურად გამოიყენებს. მხოლოდ native სამიზნე.

პროგრამარა არის ნაპოვნირა ვქნათ

8. გასუფთავება / Cleanup

იყენებს ზემოთ არჩეულ სამიზნეს და „სად“-ს (ამ მანქანაზე / SSH). ბანდლის ჩამოტვირთვის რეჟიმში არ მუშაობს.

Kubernetes-ზე მთელი სტეკის გასუფთავება შლის namespace-ს, ანუ ყველა volume-საც.

9. დიაგნოსტიკა / Diagnostics

იყენებს ზემოთ არჩეულ სამიზნეს და „სად“-ს. აჩვენებს სტატუსს, რომელ IP-ზე და პორტზე მუშაობს თითოეული პროგრამა, და ამოწმებს რეალურ პასუხს.
