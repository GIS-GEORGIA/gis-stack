## What already exists (so it is not rebuilt)

Declarative `/api/v1` with scoped tokens; dashboard (14 pages, strict CSP, no `innerHTML`/`eval`/inline handlers, KA/EN); monitoring with SQLite history, 16 threshold rules overridable in `~/.gisstack/monitor/rules.json`, alert history, availability; PostGIS / GeoServer / MapProxy managers on native, Compose and Kubernetes; encrypted offsite backups, systemd backup schedule, retention, verify, restore with pre-restore backup and rollback; multi-server profiles with pinned host keys; signed releases; preflight; operation journal; real-software integration tests.

## Findings

### Critical
None found in this audit. No open P0/P1 item remains in `docs/TECHNICAL_AUDIT.md`.

### High
| # | Finding | Status |
|---|---|---|
| H-1 | No place in the UI/API to see whether secret-holding files on the operator's machine are owner-only, or to read the audit trail. The dashboard had no Security page although the data exists. | **Fixed in this change** (`/security/posture`, `/security/audit`, Security page) |
| H-2 | Alert thresholds can only be changed by editing `rules.json`; no API/UI to view the effective rules. | Open - next |
| H-3 | Classic page `/` still needs CSP `unsafe-inline` (audit S-07); legacy `/api/*` routes remain. | Open |

### Medium
- Web map (`templates/webmap/app.js`): only search is present; scale bar, coordinate display, legend, feature identification, layer catalog / visibility and WMS/WFS/GeoJSON layers are not implemented.
- GeoServer manager: no datastore / layer / style / layer-group editing; no catalog backup from the UI.
- PostGIS manager: no saved queries, EXPLAIN, spatial-index diagnostics, `postgresql.conf` recommendations.
- Backups: GeoServer data directory, MapProxy cache and configuration backup exist as `gisstack-backup` components for native only; on-server backups are not encrypted; Compose/Kubernetes backups are not covered.
- Deployment: no automatic rollback of a failed `deploy`, no configuration comparison between a project and a running server (the multi-server comparison covers profiles only).
- Kubernetes MapProxy configuration (a ConfigMap) is read-only here.

### Long term
Fleet-wide deploy and drift remediation; typed configuration model (A-08); shell logic out of Jinja (A-07); removal of legacy `/api/*` aliases.
